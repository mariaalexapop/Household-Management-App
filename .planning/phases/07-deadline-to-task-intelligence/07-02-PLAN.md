# Plan 07-02: Suggestion server actions + Inngest daily job

**Wave:** 2 (depends on 07-01)
**Decisions:** D-03, D-04, D-06, D-07, D-08, D-09

## Goal
Create server actions for suggestion CRUD and an Inngest function that runs daily to generate suggestions from upcoming deadlines.

## Tasks

### 1. Create suggestion template mapping
**File:** `src/lib/suggestions/templates.ts`

### 2. Create Inngest function: generate-suggestions
**File:** `src/inngest/functions/generate-suggestions.ts`

- **Trigger:** Cron schedule — daily at 6:00 AM UTC
- **Logic:**
  1. For each household, scan all cars, insurance policies, and electronics
  2. For each deadline field, check if date is within 14 days from now (configurable)
  3. Check if a suggestion already exists for this (householdId, sourceModule, sourceEntityId, sourceField, deadlineDate) — skip if exists
  4. Check if suggestion was previously dismissed for this deadline cycle — skip if dismissed
  5. Use template mapping to generate title + notes
  6. Suggest the least-loaded household member as `suggestedOwnerId`
  7. Insert new suggestions with status 'pending'
- **Also trigger:** on `app/suggestion.refresh` event (for manual refresh)

### 3. Create server actions
**File:** `src/app/actions/suggestions.ts`

Actions:
- `getSuggestions(householdId)` — Fetch all pending suggestions for a household
- `acceptSuggestion(suggestionId)` — Create a task from the suggestion (using createTask), set status='accepted', store acceptedTaskId
- `dismissSuggestion(suggestionId)` — Set status='dismissed', set dismissedAt
- `refreshSuggestions()` — Emit Inngest event to regenerate suggestions now (for manual trigger)

### 4. Register Inngest function
**File:** `src/inngest/client.ts` (or wherever functions are registered)

Add `generateSuggestions` to the Inngest function registry.
