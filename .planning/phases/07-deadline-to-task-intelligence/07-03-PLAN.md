# Plan 07-03: Dashboard refactor — tasks-only timeline + DB suggestions + review card

**Wave:** 3 (depends on 07-01, 07-02)
**Decisions:** D-01, D-02, D-03

## Goal
Refactor the dashboard to show only tasks in the timeline, consume DB-backed suggestions in the sidebar, and add a "Things to review" card for old overdue items.

## Tasks

### 1. Refactor dashboard page data fetching
**File:** `src/app/(app)/dashboard/page.tsx`

Changes:
- **Remove** car, insurance, and electronics deadline queries from the timeline data
- **Add** query: fetch pending suggestions from DB (`suggestions` table where status='pending' and householdId matches)
- **Split overdue tasks:** Separate tasks >14 days overdue into a `staleOverdue` array (for review card) vs `recentOverdue` (≤14 days, stays in timeline)
- Pass `suggestions` and `staleOverdue` as new props to DashboardTimeline

### 2. Refactor DashboardTimeline — remove inline deadlines
**File:** `src/components/dashboard/DashboardTimeline.tsx`

Changes:
- **Remove** the car deadline loop (lines building `car-*` rows)
- **Remove** the insurance deadline loop (lines building `ins-*` rows)
- Timeline now only contains: tasks (chores) + activities (kids)
- **Remove** the client-side `suggestions` useMemo computation
- **Remove** the `cars`, `policies`, `electronics` props (no longer needed for timeline)
- Update Props interface accordingly

### 3. Refactor SuggestionsCard — consume DB data
**File:** `src/components/dashboard/DashboardTimeline.tsx` (or extract to own file)

Changes:
- Accept `suggestions` from DB (not computed) as prop
- Call `acceptSuggestion` / `dismissSuggestion` server actions instead of inline `createTask`
- Keep "Edit" button that navigates to `/chores?action=new&title=...&startsAt=...`
- Remove `Assign to [Name]` → replace with `Accept` (creates task with suggested owner)
- Show suggestion source module dot color

### 4. Add "Things to review" card
**File:** `src/components/dashboard/DashboardTimeline.tsx`

New sidebar card for tasks >14 days overdue:
- Header: "Things to review" with warning icon
- List stale overdue tasks with title, how long overdue, and quick actions: "Reschedule" (link to chores with edit) / "Mark done"
- Only shows if staleOverdue.length > 0

### 5. Filter overdue in timeline
**File:** `src/components/dashboard/DashboardTimeline.tsx`

- Only show overdue tasks where `differenceInCalendarDays(now, taskDate) <= 14` in the amber "Overdue" section
- Tasks older than 14 days are NOT in the timeline at all (they're in the review card)

## Verification
- [ ] Dashboard timeline shows ZERO car/insurance/electronics rows
- [ ] Dashboard timeline shows only chores + kids activities
- [ ] Suggestions card reads from DB, not client-side computation
- [ ] Accept creates a task and marks suggestion as accepted
- [ ] Dismiss persists — suggestion doesn't reappear on reload
- [ ] Tasks >14 days overdue appear in "Things to review" card, not in timeline
